## Available integrations

| Integration | What it does |
| --- | --- |
| GitHub | Syncs pull requests, reviews and releases. |
| Slack | Sends review reminders and release notes. |
| Jira | Links issues to projects. |

## Permissions

Only workspace admins can add or remove integrations. Read more on the [GitHub docs](https://docs.github.com/).

> [!CAUTION]
> Removing an integration stops syncing immediately. History it already synced is kept.
