## Install the CLI

The Elula CLI works on macOS, Linux and Windows.

```bash
npm install -g @elula/cli
```

## Create a workspace

Sign in and create a workspace for your team:

```bash
elula login
elula workspaces create acme
```

## Connect a repository

Add an `elula.config.ts` file to the root of your repository:

```ts title="elula.config.ts" showLineNumbers
import { defineConfig } from "@elula/cli";

export default defineConfig({
  workspace: "acme",
  releases: { branch: "main" },
});
```

> [!WARNING]
> Elula needs read access to pull requests. Grant it when your Git provider asks.
